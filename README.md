# karotkriss/cwcli

Homebrew tap for [cwcli](https://github.com/karotkriss/caffeinated-whale-cli) (`caffeinated-whale-cli`), the CLI for managing local Frappe/ERPNext Docker instances.

## Install

```
brew tap karotkriss/cwcli
brew install cwcli
```

Or, one shot:

```
brew install karotkriss/cwcli/cwcli
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
